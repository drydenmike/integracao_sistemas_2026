## Controlo de versões nesta UC

O controlo de versões permite registar cada alteração feita aos artefactos da UC, com data, autor e uma mensagem que explica o porquê da mudança. Assim, é possível seguir a evolução de cada trabalho desde a primeira versão até à entrega final e perceber em que momento foi tomada cada decisão. Caso algo corra mal, posso sempre comparar versões ou voltar a um estado anterior sem perder trabalho. Além disso, o histórico de commits funciona como evidência do percurso de aprendizagem, tornando o processo transparente tanto para mim como para o docente.
